### Selected work

**[FederatedWeatherCC](https://github.com/Attilio-Di-Vicino/FederatedWeatherCC) · Federated weather forecasting**  
Collaborative research on forecasting from distributed weather-station data using Transformer and Crossformer models. The repository includes data preprocessing, centralized training, and federated client/server code built with Python, PyTorch, and Flower. I contributed substantially to the research behind the accompanying BigHPC paper, which credits three authors equally and names me as corresponding author.

**[Samsung Tizen 4 USB root](https://github.com/GiuseppeFiorillo/samsung-tv-usb-root-kant-m2) · Embedded systems & reverse engineering**  
A project I'm especially proud of: I adapted Luminger's USB-root research to Samsung's 2018 Kant-M2 platform and validated an interactive root shell on a QE49Q6FNA running firmware T-KTM2DEUC 1400.2, without modifying the firmware. The repository documents the platform-specific analysis and tooling.

**[JCAM_Cuda](https://github.com/GiuseppeFiorillo/JCAM_Cuda) · GPU computing for biological simulation · [Paper](https://doi.org/10.3390/appliedmath5040178)**  
I ported an existing MATLAB implementation to CUDA for a numerical model of tumor angiogenesis. The published work implements GPU kernels for pivot selection, row swapping, and Gaussian elimination. It reports up to **113× speedup on an NVIDIA H100** against the sequential CPU implementation in the paper's benchmarks.

**[Esercitazioni-C-Parthenope](https://github.com/GiuseppeFiorillo/Esercitazioni-C-Parthenope) · Learning resources in C**  
A collection of programming exercises for fellow students at the University of Naples Parthenope, covering sorting, text processing, set operations, and exam practice.
